# 40 Days of Terraform, Kubernetes and DevOps

A hands-on DevOps learning journey using WSL2 Ubuntu.
## Learning Roadmap

- Days 1–15: Terraform and Infrastructure as Code
- Days 16–30: Kubernetes
- Days 31–35: Monitoring and CI/CD
- Days 36–40: Integrated DevOps portfolio projects

## Environment

- Windows + WSL2 Ubuntu
- Visual Studio Code
- Terraform
- Git
- Docker
- kubectl
- Minikube
- Floci (for local AWS service emulation)


## Day 01

- Learned IaC and Terraform concepts
- Installed Terraform
- Created a Terraform local-file resource
- Practiced init, fmt, validate, plan and apply
- Inspected Terraform state
- Practiced debugging
